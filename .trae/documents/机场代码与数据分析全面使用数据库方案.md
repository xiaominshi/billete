2. 数据分析 DB-only 确认与优化
- 维持所有统计接口仅从 history 表查询；将前端过滤（如月份过滤）下沉到后端查询以减少前端计算。

3. 性能与稳定性
- 在 Neon 创建索引：
  - CREATE INDEX IF NOT EXISTS idx_history_ts ON history (timestamp);
  - CREATE INDEX IF NOT EXISTS idx_history_code ON history (code);
  - CREATE UNIQUE INDEX IF NOT EXISTS idx_airports_code ON airports (code);
- 保留 pool_pre_ping + NullPool；确认 sslmode=require 与 channel_binding=require 按 URL 生效。

- 保留“按 code 去重”规则；如需历史完整保留（同一 code 多版本），可改为新增版本号字段替代删除。
