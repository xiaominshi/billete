# 强制重置代码至 GitHub 最新版本

收到，既然您不需要保留当前的代码修改，我将直接执行**强制重置**操作，将当前目录下的所有文件恢复到 GitHub 上的最新状态。

## 执行步骤

1.  **同步远程状态**
    *   执行 `git fetch --all` 获取远程仓库的最新信息。

2.  **强制重置 (Hard Reset)**
    *   执行 `git reset --hard origin/main`
    *   **警告**：这一步将**永久丢弃**当前本地的所有修改（包括二维码功能、数据库字段变更等），使本地代码与 GitHub 完全一致。

3.  **拉取最新**
    *   执行 `git pull` 确保没有任何遗漏的更新。

4.  **验证完整性**
    *   检查当前 Git 状态，确保显示 "working tree clean"（工作区干净）。
    *   确认关键文件已恢复为官方版本。

请确认执行此操作（当前所有未提交的改动将被删除）。
