# 航班号显示优化方案 (Fix Flight Number Display)

您指出的问题是：在前端视觉卡片中，航班号显示了舱位代码（例如 `3U3803N`），而您希望只显示纯航班号（`3U3803`），去掉后面的舱位字母（`N`, `B` 等）。

## 问题分析
这是 `billete_logic.py` 中的正则表达式提取逻辑过于宽泛导致的。目前的逻辑可能把航班号后面的舱位代码也一起抓取了。

根据您提供的示例数据：
`3U3804 N 04JAN` -> 航班号 `3U3804`, 舱位 `N`
`3U6901 B 05JAN` -> 航班号 `3U6901`, 舱位 `B`

## 修复方案

1.  **修改 `billete_logic.py`**:
    *   定位提取航班号的正则表达式。
    *   调整正则，确保只提取 **2位字母/数字 + 3-4位数字**。
    *   明确排除紧跟在数字后面的单个字母（舱位）。

2.  **前端验证**:
    *   不需要修改前端代码，只要后端逻辑修正，生成的 JSON 数据正确，前端就会自动显示正确的航班号。
