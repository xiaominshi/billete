为了进一步提升翻译速度，我制定了以下 3 个层面的优化计划：

### 1. 异步数据库写入 (`server.py`) - **最关键优化**
*   **问题**：目前每次翻译完，服务器都要等待“保存历史记录”到数据库完成后，才把结果返回给前端。在 Render 连接远程数据库（Neon）的情况下，这会产生几百毫秒的阻塞。
*   **方案**：将 `logic.save_to_history` 放入**后台线程**执行。
*   **效果**：服务器计算完结果后**立即**返回给前端，不再等待数据库写入。这会让用户感觉“瞬间”完成。

### 2. 正则表达式预编译 (`logic.py`)
*   **问题**：代码中在循环内部反复调用 `re.match` / `re.search`，虽然 Python 有缓存，但仍有函数调用开销。
*   **方案**：将所有正则表达式在 `AmadeusParser` 类初始化时预编译（`re.compile`）。
*   **效果**：减少 CPU 消耗，提升解析大量文本时的速度。

### 3. 减少日志 I/O (`logic.py`)
*   **问题**：`log` 函数使用 `print()`，这是同步 I/O 操作。
*   **方案**：减少不必要的日志输出，或仅将日志存入内存列表（`self.logs`），除非出错否则不打印到控制台。
*   **效果**：微幅提升处理速度。

### 执行顺序
1.  修改 `server.py`：引入 `threading`，异步保存历史记录。
2.  修改 `logic.py`：预编译正则，优化日志。
3.  推送 Git。
