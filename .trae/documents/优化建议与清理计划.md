您选择了 **前端性能优化**。这将把 `index.html` 中的 CSS 和 JS 代码分离到独立文件中，使代码更清晰，加载更快。

**实施计划：**

1. **创建目录结构**：

   * `BilletePython/static/css/`

   * `BilletePython/static/js/`

2. **分离样式表 (CSS)**：

   * 将 `index.html` 中 `<style>` 标签内的所有 CSS 代码提取到 `static/css/style.css`。

   * 在 HTML 中使用 `<link>` 标签引入该文件。

3. **分离脚本 (JS)**：

   * 将 `index.html` 中 `<script>` 标签内的所有 JavaScript 代码提取到 `static/js/main.js`。

   * 在 HTML 中使用 `<script src="...">` 标签引入该文件。

   * *已确认代码中没有服务端模板变量注入，可以直接分离。*

4. **清理 HTML**：

   * 删除原文件中冗长的内联代码，大幅减小文件体积（预计减少 2000+ 行）。

**执行后效果：**

* `index.html` 将变得非常简洁。

* 浏览器可以缓存 CSS 和 JS 文件，加快二次访问速度。

* 开发时只需修改独立文件，不再需要在庞大的 HTML 中翻找。
