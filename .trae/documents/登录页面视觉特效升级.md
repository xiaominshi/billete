# 登录页面炫酷动画升级计划

为了打造更具视觉冲击力的登录体验，我将从背景、卡片交互和元素入场三个维度添加动画效果。

## 1. 动态流光背景 (Animated Gradient Background)
- 将静态渐变改为 **动态流光** 效果，背景色会在靛蓝、深紫和青色之间缓慢流动，营造梦幻氛围。
- 添加 **漂浮的几何图形**（如半透明的圆形），在背景中缓慢移动和旋转，增加画面层次感。

## 2. 3D 悬浮卡片 (3D Tilt Effect)
- 为登录卡片添加 **3D 视差倾斜** 效果。当鼠标在卡片上移动时，卡片会跟随鼠标位置产生微小的倾斜，模拟真实物体的质感。
- 增加 **光泽扫光 (Sheen)** 效果，随鼠标移动掠过卡片表面。

## 3. 元素交错入场 (Staggered Entrance)
- 页面加载时，Logo、标题、输入框和按钮将不再同时出现，而是按顺序 **依次飞入** 或淡入（Staggered Animation），让视觉引导更流畅。

## 4. 交互微效
- **按钮脉冲**：登录按钮在悬停时产生柔和的光晕脉冲。
- **输入框激活**：输入框获得焦点时，边框会有光流扩散的效果。

这些效果将主要通过 CSS3 和轻量级原生 JavaScript 实现，保证流畅度且不增加额外依赖。
