您反馈的“马德里-马德里-马德里”问题，是一个典型的逻辑拼接错误。

### 原因分析
在 `server.py` 中，生成 `route_info`（航线字符串）的逻辑非常简单粗暴：
```python
origin = f[0]['origin']     # 起点 = 第一段的出发地 (马德里)
dest = f[-1]['dest']        # 终点 = 最后一段的到达地 (马德里)

if is_return:               # 如果是往返
    route_info = f"{origin}-{dest}-{origin}" 
    # 结果 = 马德里 - 马德里 - 马德里
```
看出来了吗？代码错误地把“最终回到的地点”当成了“目的地”。

### 修复方案
我们需要找到真正的“目的地”（折返点）。
对于往返行程：
*   **起点** = 第一段的出发地。
*   **折返点** = **回程第一段的出发地**（或者去程最后一段的到达地）。
*   **终点** = 最后一段的到达地。

正确的拼接应该是：`起点 - 折返点 - 终点`。

### 执行步骤
1.  **修改 `server.py`**：优化航线字符串生成逻辑。对于往返行程，使用“回程航班的出发地”作为中间的那个地名。
2.  **重启服务**：验证修复。
