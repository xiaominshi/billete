# Git 提交并推送 (Git Commit & Push)

您确认需要同时执行提交 (Commit) 和推送 (Push) 操作。

## 执行步骤 (Steps)
1.  **进入目录**: `cd BilletePython`
2.  **添加文件**: `git add .`
3.  **提交更改**: `git commit -m "Update: Optimize Visual Card layout, i18n fixes, and PDF scaling"`
4.  **推送到远程**: `git push`

这将把您的最新更改同步到远程仓库（如 GitHub/GitLab）。
