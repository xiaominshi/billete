# 主页面风格升级计划：航空主题 (Aviation Theme)

为了与新的登录界面保持一致，我将把主页面 (`index.html`) 也升级为 **沉浸式航空主题**。

## 1. 视觉基础 (Visual Foundation)
- **背景同步**: 引入与登录页相同的“云端之上”背景图，保留呼吸动效 (Ken Burns Effect) 和深色遮罩。
- **粒子网络**: 在背景中添加全球航线粒子动画，营造统一的科技感。
- **全局深色磨砂 (Dark Glassmorphism)**:
    -   所有功能卡片（翻译、历史、机场管理）将改为 **深色半透明磨砂玻璃** 材质。
    -   文字颜色调整为白色/浅灰，确保在深色背景下的高可读性。

## 2. 组件样式升级 (Component Restyling)
- **输入框 & 文本域**: 改为深色半透明背景 (`rgba(0,0,0,0.3)`) + 白色文字 + 发光边框。
- **按钮**:
    -   主按钮（如“开始翻译”）改为 **白色实心** 样式（与登录页一致），增强点击欲望。
    -   次级按钮（如“复制”、“清除”）改为半透明幽灵按钮。
- **列表与表格**:
    -   历史记录和机场列表将去除白色背景，改为透明或轻微加深的条纹样式。
    -   滚动条美化为细长的深色样式。
- **统计图表适配**:
    -   调整 Chart.js 配置，将坐标轴、图例文字颜色改为白色，以适配深色背景。

## 3. 头部导航优化 (Header Refinement)
- **Logo 动画**: 引入 SVG 飞机图标和浮动动画。
- **用户信息栏**: 改为悬浮的玻璃胶囊样式，更加精致。

## 4. 实施步骤
1.  **CSS 重构**: 更新 CSS 变量，引入背景、动画和磨砂玻璃样式类。
2.  **HTML 结构调整**: 添加背景层和 Canvas 容器。
3.  **JS 逻辑补充**: 移植粒子动画脚本；更新图表配置的颜色参数。

这个改动将使整个系统看起来像是一个高端的航空控制台。
