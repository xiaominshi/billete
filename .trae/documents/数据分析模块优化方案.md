# 优化登录界面计划 (Login Page Makeover)

既然您希望专注于登录界面的优化，我将为您打造一个 **现代、美观且具有交互性** 的登录页面，完全替代当前简陋的 Bootstrap 版本。

## 设计目标
1.  **视觉升级**:
    -   **移除 Bootstrap**: 转为使用自定义 CSS，以匹配主页面的设计风格（Inter 字体、圆角、阴影）。
    -   **背景**: 采用柔和的靛蓝/紫色渐变背景，营造专业感。
    -   **卡片设计**: 使用悬浮卡片式布局，带有细腻的阴影和微动效。
2.  **交互增强**:
    -   **浮动标签 (Floating Labels)**: 输入框获得焦点时，标签平滑上移。
    -   **密码可见性切换**: 添加“眼睛”图标，点击可查看/隐藏密码。
    -   **加载反馈**: 点击登录后按钮显示加载动画。
    -   **错误提示**: 如果登录失败，错误信息将以更优雅的方式展示（带抖动动画）。

## 实施细节 (`templates/login.html`)
-   引入 `Inter` 字体。
-   使用 Flexbox 实现完美居中。
-   使用 SVG 图标增强视觉提示。
-   添加简单的 JavaScript 处理交互（密码切换、表单提交状态）。

这是一个纯前端的优化，不会影响后端逻辑。
