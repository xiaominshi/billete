您选择了 **PDF 导出功能**。这将允许用户生成专业、美观的行程单文件，便于发送给客户。

**实施计划：**

1.  **引入 PDF 生成库**：
    *   使用 Python 的 `reportlab` 库（轻量、功能强大）。需要添加到 `requirements.txt`。

2.  **后端实现 (`pdf_generator.py` & `server.py`)**：
    *   创建一个新的模块 `pdf_generator.py`，专门负责 PDF 的绘制逻辑。
    *   **设计模板**：
        *   **页眉**：公司 Logo（如果没有则使用默认文本）、标题 "Flight Itinerary / 行程单"。
        *   **旅客信息**：以清晰的表格列出所有旅客姓名、票号。
        *   **航班详情**：为每个航段创建一个卡片或表格行，包含：
            *   日期、时间（起飞/到达）
            *   机场（三字码 + 名称）
            *   航班号、机型、舱位
            *   **航空公司 Logo**（预置常用航司 Logo 或显示文字）。
        *   **行李信息**：显示手提和托运额度图标。
        *   **页脚**：包含用户专属二维码（如果有）和联系方式。
    *   在 `server.py` 添加 `/download_pdf` 路由，接收 JSON 数据（或 History ID），返回 PDF 文件流。

3.  **前端集成 (`index.html` / `main.js`)**：
    *   在现有的结果展示区（"Visual Card" 旁边）添加一个显眼的 **"📄 导出 PDF"** 按钮。
    *   点击按钮时，将当前的解析结果数据发送给后端生成 PDF 并触发下载。

**资源需求：**
*   需要一些基础的字体文件（支持中文，如思源黑体或系统字体），以防止中文乱码。
*   需要准备一些占位图标（飞机、行李）。

**预期效果：**
用户点击按钮后，浏览器自动下载一个名为 `Itinerary_2023xxxx.pdf` 的文件，打开后是一份可以直接打印或通过微信/邮件发送的专业行程单。
